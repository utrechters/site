## Expat Bivalent

**Expat Bivalent** (`/expat-bivalent`) is a "would you rather" identity game for expats: pick two countries you've lived in, tap through paired cultural moments, and get a shareable percentage split showing where your identity lands — e.g., "60% Swiss, 40% Romanian". The game is fully client-side and static; item content lives in plain JSON files so the community can add cultural references without touching any code. See [CONTRIBUTING — How to Add an Expat Bivalent Item](CONTRIBUTING.md#how-to-add-an-expat-bivalent-item).
